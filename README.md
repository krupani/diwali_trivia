# 🪔 Diwali Ramayana Trivia

A Diwali-themed trivia quiz that walks you through the story of the Ramayana — from Rama's birth to his return to Ayodhya, which is why we celebrate Diwali.

Made for kids (10–15) and adults new to Diwali. No timer, no score, just a story in a fun quiz type format.

---

## How to Play

1. Download and open `index.html` in any browser or use the [Github Page link](https://krupani.github.io/diwali_trivia/)
2. Click **Begin the Journey**.
3. Pick an option — it turns yellow, then green (correct) or red (wrong).
4. Read the short story that explains the answer, then click **Next**.
5. Journey through all 25 questions and 3 story interludes.
6. Finish on the 🎆 **Happy Diwali** screen.

Use the **×** in the top-right to exit any time.

**Keyboard:** `↑`/`↓` to move, `Enter` to select, `1`–`4` for quick answers, `Esc` to exit.

---

## Running It

- **Locally:** double-click `index.html`. Done.
- **GitHub Pages:** Use the [Link](https://krupani.github.io/diwali_trivia/).

---

## Customizing

All questions and stories live in `data/diwali_trivia.js` — edit that file to add or change questions.
